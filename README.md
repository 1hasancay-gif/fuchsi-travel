# Fuchsi Travel 🦊🇩🇪

PWA prototipi: Almanca A1 öğrenme + Almanya yolculuğu.

## Telefonla kurulum
1. Bu klasörü bir HTTPS statik site olarak yayınla (ör. GitHub Pages).
2. Telefonda siteyi Chrome ile aç.
3. Ana ekrana ekle / "Yükle" düğmesine bas.

## Not
Bu sürüm internet olmadan da daha önce açılan temel ekranları önbellekten çalıştırır. Gerçek Fuchsi AI sohbeti için daha sonra güvenli bir backend bağlantısı eklenmelidir.
